# Portfolio com jogo

Portfólio simples feito com HTML, CSS e JavaScript, com o projeto PokéGuess em destaque.

## Estrutura

```text
portfolio/
├── index.html
├── pokeguess.html
│
├── css/
│   ├── style.css
│   └── pokeguess.css
│
├── js/
│   ├── script.js
│   └── pokeguess.js
│
├── assets/
│   ├── img/
│   └── icons/
│
└── README.md
```

## O que a página contém

- cabeçalho com nome do projeto;
- slogan;
- área sobre/projetos;
- formulário simples de contato;
- consulta dos meus projetos públicos no github;
- página dedicada ao projeto PokéGuess.

## Como abrir

Abra `index.html` no navegador ou use uma extensão de servidor local no VS Code.

## Observação

As pastas `assets/img` e `assets/icons` foram criadas para facilitar futuras imagens e ícones do portfólio.
